# Engineering Materials

This repository contains all engineering materials, CAD models, schematic diagrams, source code, and technical documentation for the autonomous vehicle **Meteoro**, developed by team **The Pits JO** from **Instituto Técnico Jesús Obrero (ITJO)** for the **WRO Future Engineers 2026** competition.

## Content

* [`README.md`](./README.md): Main technical documentation in English.
* [`README_ES.md`](./README_ES.md): Complete technical documentation in Spanish.
* [`LICENSE`](./LICENSE): MIT open-source license granted by team **The Pits JO**.
* [`.gitignore`](./.gitignore): Configuration file to ignore temporary files and compilation binaries.
* [`src/`](./src/): Control software source code for all components programmed to participate in the competition.
* [`models/`](./models/): 3D model files used by 3D printers, laser cutters, and CNC machines to manufacture vehicle components.
* [`photos/`](./photos/): Unified photo gallery containing official team photos, required vehicle views, and build/programming logs.
* [`video/`](./video/): File containing the direct link to the driving demonstration video on the track.
* [`schematics/`](./schematics/): Schematic diagrams of electromechanical components, illustrating all elements (electronic components and motors) used in the vehicle and how they connect to each other.
* [`docs/`](./docs/): Additional documentation, datasheets, pinout tables, and pit stop checklists.
