# Materiales de Ingeniería

Este repositorio contiene los materiales de ingeniería del modelo de vehículo autónomo participante en la competencia WRO Future Engineers.

## Contenido

* `t-photos` contiene 2 fotos del equipo (una oficial y una foto divertida con todos los integrantes del equipo).
* `v-photos` contiene 6 fotos del vehículo (desde cada lado, desde arriba y desde abajo).
* `video` contiene el archivo `video.md` con el enlace a un video donde se muestra la demostración de manejo.
* `schemes` contiene uno o varios diagramas esquemáticos en formato JPEG, PNG o PDF de los componentes electromecánicos, ilustrando todos los elementos (componentes electrónicos y motores) utilizados en el vehículo y cómo se conectan entre sí.
* `src` contiene el código del software de control para todos los componentes que fueron programados para participar en la competencia.
* `models` es para los archivos de los modelos utilizados por impresoras 3D, máquinas de corte láser y máquinas CNC para fabricar los elementos del vehículo. Si no hay nada que añadir en esta ubicación, el directorio puede ser eliminado.
* `other` es para otros archivos que se puedan utilizar para entender cómo preparar el vehículo para la competencia. Puede incluir documentación sobre cómo conectarse a una SBC/SBM y cargar archivos allí, conjuntos de datos (datasets), especificaciones de hardware, descripciones de protocolos de comunicación, etc. Si no hay nada que añadir en esta ubicación, el directorio puede ser eliminado.
